# DCF Valuation — Inditex (ITX)


Modelo de valoración por Descuento de Flujos de Caja (DCF) para Inditex,
desarrollado como parte de un proyecto personal simulando el rol de 
analyst en J.P. Morgan.

## Metodología

- Proyección de Free Cash Flow a 5 años (FY2026-FY2030)
- WACC: 8%
- Tasa de crecimiento terminal: 2.5%
- Precio objetivo: 49.62€ por acción
- Precio de mercado: 56.00€ → Downside del 11.4%

## Estructura del modelo (pestañas Excel)

- **Assumptions** — hipótesis de crecimiento, márgenes y parámetros DCF
- **Income Statement** — proyección de cuenta de resultados a 5 años
- **Free Cash Flow** — cálculo del FCF anual
- **DCF Valuation** — descuento de flujos y precio objetivo
- **Sensitivity** — análisis de sensibilidad WACC vs tasa de crecimiento terminal

## Datos base (FY2025 real)

- Ventas: 39.900M€
- EBITDA: 11.267M€
- FCF: 4.700M€
- Caja neta: 11.000M€
